# Registro de alumnos - Java For Testers

Mini proyecto educativo para practicar:

- Herencia
- DTO
- DAO
- ArrayList
- Scanner
- Métodos
- Condicionales
- Switch
- Instancias de clases

## Ejecutar

Abre el proyecto en IntelliJ IDEA y ejecuta:

`com.testeracademy.app.Main`

También puedes usar Maven:

```bash
mvn clean compile
```

## Flujo

1. El menú permite crear un alumno.
2. El alumno se guarda en memoria.
3. El menú permite consultar un alumno por su ID.
4. El proyecto inicia con 10 alumnos de ejemplo.

No utiliza base de datos. Los datos existen únicamente mientras el programa está en ejecución.
